# ✨ Mur de Citations Inspirantes - Projet Django

Bienvenue sur le projet **Mur de Citations** ! Il s'agit d'une application web créative développée avec Python et Django, où les utilisateurs peuvent partager leurs citations préférées.

## 🎨 Fonctionnalités
* **Affichage sous forme de mur (Grille)** : Les citations sont affichées dans de jolies cartes.
* **Génération de couleurs aléatoires** : Chaque nouvelle citation reçoit une couleur de fond pastel/générée aléatoirement, ce qui rend le mur unique et coloré !
* **Ajout de citations** : Un formulaire simple pour ajouter un auteur et un texte.
* **Interface d'administration** : Gestion des citations via l'admin Django.

## 🛠️ Technologies utilisées
* **Backend** : Python 3 & Django
* **Frontend** : HTML5, CSS3 (Grid layout)
* **Base de données** : SQLite (par défaut avec Django)
